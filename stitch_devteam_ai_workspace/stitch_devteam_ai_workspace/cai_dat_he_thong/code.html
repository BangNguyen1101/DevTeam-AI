Rào chắn An toàn & Guardrails

Quy định nghiêm ngặt quyền hạn tự trị của Agent. Ngăn chặn sự cố phá hoại cấu trúc dữ liệu hoặc rò rỉ mã nguồn.

3/3 Active Policies
database
Bắt buộc Phê duyệt người dùng với thao tác Database Drop/Alter High Severity

Agent Coder không được phép tự động thực thi các migration SQL có từ khóa DROP TABLE, ALTER COLUMN hoặc xóa schema nếu không có xác nhận của Tech Lead qua Telegram/Web.

undo
Tự động Rollback Git commit nếu Unit Test thất bại CI/CD Guard

Nếu bộ kiểm thử tự động (Jest/PyTest) của QA Agent phát hiện lỗi sau khi Coder Agent tạo commit, hệ thống sẽ thực thi git revert HEAD ngay lập tức và phân công lại task kèm call-stack log.

spellcheck
Zero-Hallucination Strict Mode Compiler Gate

Chặn sinh code không có kiểm tra kiểu dữ liệu (TypeScript type check / Python mypy). Trình phân tích tĩnh AST bắt buộc 100% các hàm mới phải có docstring và type definitions hoàn chỉnh.
